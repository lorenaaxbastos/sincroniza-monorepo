# Design tokens

Estes tokens são gerados automaticamente a partir do `@sincroniza/tokens` e disponibilizados em `tokens.css` e `global.css`. Eles garantem a consistência visual de cores, espaçamentos, tipografia e elevação em todos os projetos. Podem ser sobreescritos por projetos, garantindo a IDV adequada para cada cliente.

<div style={{marginBottom: '6rem'}}></div>

## 2. Escala de espaçamento (`--spacing-*`)

## 8. Utilitários e classes globais

<div style={{marginBottom: '2rem'}}></div>

### Acessibilidade (`.sinc-sr-only`)

Para esconder elementos visualmente, mas mantê-los legíveis por leitores de tela:

```html
<span class="sinc-sr-only">Descrição legível apenas por leitores de tela</span>
```

Com o modificador `--focusable` (usado no `Skip Link` de acessibilidade), o elemento torna-se visível quando focado com teclado (`Tab`):

```html
<a href="#main-content" class="sinc-sr-only --focusable">
  Pular para o conteúdo principal
</a>
```

<div style={{marginBottom: '6rem'}}></div>

### Anel de foco global

Todos os elementos interativos recebem automaticamente um outline visível quando focados via teclado (`:focus-visible`):

* **Outline:** `2px solid var(--color-feedback-info)`
* **Offset:** `-3px`
* **Border Radius:** `var(--radii-sm)`

<div style={{marginBottom: '6rem'}}></div>

## 9. Reset de CSS e estilos de base

O arquivo `global.css` aplica regras globais de normalização para garantir consistência entre navegadores e evitar surpresas de layout.

<div style={{marginBottom: '2rem'}}></div>

### Modelo de caixa e espaçamentos universais (`*`)

Todos os elementos e pseudo-elementos (`*::before`, `*::after`) adotam o modelo de caixa `border-box` e têm suas margens e paddings zerados por padrão:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}
```
<div style={{marginBottom: '4rem'}}></div>

### Unidade de medida base e rolagem suave (`html`)

A raiz do documento redefine o tamanho de fonte base para `62.5%` para facilitar o cálculo de rem em base decimal e ativa a rolagem suave nativa para navegação por âncoras:

* **`1rem = 10px`** (`1.6rem = 16px`, `2.4rem = 24px`).
* **`scroll-behavior: smooth`:** Garante deslize suave ao clicar em links que apontam para IDs da mesma página.

<div style={{marginBottom: '4rem'}}></div>

### Ocultamento estrito (`[hidden]`)

Garante que qualquer elemento contendo o atributo nativo HTML `hidden` seja completamente removido do fluxo visual, sobrescrevendo eventuais regras acidentais de `display`:

```css
[hidden] {
  display: none !important;
}
```

<div style={{marginBottom: '4rem'}}></div>

### Remoção de estilos de lista (ul, ol)

Remove as marcas de ponto (bullet points) e numerações nativas de listas, mantendo a estrutura semântica dos elementos no HTML sem interferir visualmente em menus, navbars e componentes de grupo:

```css
ul,
ol {
  list-style: none;
}
```

<div style={{marginBottom: '4rem'}}></div>

### Bloqueio de scroll global (`:has()`)

Quando um modal ou gaveta lateral está aberto, o sistema bloqueia a rolagem do fundo automaticamente via CSS, sem necessidade de manipular classes diretamente no `body`:

```css
:root:has([data-state='open'][data-scroll-lock]) {
  overflow: hidden !important;

  body,
  [data-scrollable] {
    overflow: hidden !important;
  }
}
```

<div style={{marginBottom: '4rem'}}></div>

### Recálculo dinâmico da altura do Header (`:has()`)

O `:root` detecta automaticamente a presença de uma Topbar ativa na página via atributo `data-has-topbar="true"` e recalcula a variável global `--sinc-header-height` sem necessidade de JavaScript. Isso garante que contêineres vizinhos, o `scroll-padding-top` de âncoras e a `Sidebar` ajustem suas posições instantaneamente.

```css
:root:has([data-has-topbar='true']) {
  --sinc-header-height: calc(
    var(--sinc-header-main-height) + var(--sinc-topbar-height)
  );
}
```

<div style={{marginBottom: '4rem'}}></div>

### Tratamento de imagens e mídia

* **Midia Responsiva:** `img`, `video`, `svg` e `iframe` possuem `max-width: 100%` por padrão.
* **Imagens Decorativas Quebradas:** Imagens com `role="presentation"` sem atributo `src`, com `src=""` ou com a classe `.is-broken` são ocultadas do fluxo visual e de leitura:

```css
img[role='presentation'] {
  &:not([src]),
  &[src=''],
  &[src='#'],
  &.is-broken {
    display: none !important;
  }
}
```

### Reset de elementos nativos (`button` e `a`)

* **`button`**: Remove bordas, fundos nativos do sistema e estiliza a propriedade `cursor: pointer`, herdando a tipografia do contexto.
* **`a`**: Remove o sublinhado padrão (`text-decoration: none`), aplica a cor `var(--color-text-link)` e `var(--color-text-link-hover)` no `hover` e `focus-visible` e utiliza `overflow-wrap: anywhere` para evitar que URLs longas quebrem o layout em telas menores.
